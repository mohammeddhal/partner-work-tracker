# تطبيق متابع عمل الشركاء (Partner Work Tracker) ⏱️🚀

تطبيق احترافي متكامل مبني باستخدام **Flutter** و **Firebase** لمتابعة وحساب ساعات ونقاط ونسب مجهود الشركاء بدقة متناهية وبشكل آلي بالكامل بدون أي تدخل يدوي.

---

## 🌟 الميزات الرئيسية

1. **تسجيل العمل الذكي والمباشر**:
   - زر كبير نابض تفاعلي `بدء العمل` و `إنهاء العمل`.
   - عداد وقت مباشر رقمي يعتمد على توقيت الخادم (`Server Timestamp`).
   - استمرار العداد بدقة حتى في حال إغلاق التطبيق أو إعادة تشغيل الهاتف.
   - دعم تسجيل عدة جلسات في اليوم الواحد مع دمجها تلقائياً.
   - منع بدء جلستين في نفس الوقت (`Single Active Session Constraint`).
   - حماية ضد الضغط المزدوج على الأزرار (Debounce & Action Locking).

2. **نظام النقاط والمجهود العادل**:
   - احتساب النقاط بناءً على نسبة تحقيق الالتزام المطلوب لكل شريك:
     $$\text{Daily Points} = \left(\frac{\text{Actual Worked Minutes}}{\text{Required Daily Minutes}}\right) \times 100$$
   - استخدام وحدة **الدقائق الصحيحة (Integers)** داخلياً لمنع أي أخطاء ناجمة عن الأرقام العشرية.
   - دعم تحديد سقف أعلى للنقاط اليومية (Daily Points Cap) اختيارياً من قبل المدير.
   - احتساب **نسبة المجهود الشهرية (% Effort Share)** لكل شريك من إجمالي نقاط الشركاء:
     $$\text{Partner Effort \%} = \left(\frac{\text{Partner Total Monthly Points}}{\sum \text{All Partners Monthly Points}}\right) \times 100\%$$

3. **التقارير والمقارنة التفاعلية**:
   - مقارنة مباشرة بين الشركاء (محمد ومسعود) مع رسوم بيانية دائرية وشريطية تفاعلية (`fl_chart`).
   - إحصائيات تفصيلية: إجمالي الساعات، الساعات الإضافية (Overtime)، الساعات الناقصة (Deficit)، أيام الحضور، أيام الغياب، ونسبة الالتزام.
   - زر للمدير لإغلاق الشهر (`إغلاق الشهر`) وتوليد لقطة نهائية مجمدة (Snapshot) غير قابلة للتعديل.
   - تبويب **الأشهر السابقة** لاستعراض سجل التقارير الشهرية المؤرشفة السابقة.

4. **لوحة التحكم وصلاحيات الإدارة (RBAC)**:
   - صلاحيات مخصصة للـ `Partner` والـ `Admin`.
   - إمكانية تعديل الساعات اليومية المطلوبة لكل شريك وأيام العمل الأسبوعية.
   - إمكانية إضافة جلسة يدوياً، تعديل جلسة، أو حذف جلسة خاطئة مع **إلزام المدير بكتابة سبب التعديل** وحفظه في سجل التدقيق.
   - سجل تدقيق غير قابل للحذف أو التعديل (`Audit Log`) يسجل جميع العمليات الحساسة.

5. **التصميم واللغة والوضع الليلي**:
   - واجهة عربية أصيلة تدعم الـ RTL بالكامل مع خط عربي حديث وأنيق.
   - دعم الوضعين الفاتح والداكن (`Light Mode` & `Dark Mode`).
   - تنبيهات محلية للجلسات الطويلة (`Local Notifications`).
   - دعم العمل دون اتصال بالإنترنت (`Offline Persistence`) مع شريط تنبيه واضح.

## 🏗️ البنية المعمارية (Feature-First Clean Architecture)

```
lib/
├── core/
│   ├── constants/             # الألوان، الثوابت، النصوص العربية (AppStrings)
│   ├── theme/                 # ثيمات Light و Dark بتصميم عصري وأنيق
│   ├── utils/                 # محرك الحسابات (PointsCalculator) ومحول التواريخ
│   ├── widgets/               # المكونات المشتركة (AppButton, AppCard, StatBadge...)
│   └── services/              # التنبيهات المحلية والتحقق من الشبكة
├── features/
│   ├── auth/                  # المصادقة، نموذج المستخدم والصلاحيات (Admin/Partner)
│   ├── tracker/               # العداد المباشر، تسجيل الدخول/الخروج، ملخص اليوم
│   ├── history/               # سجل الجلسات اليومية وتفاصيل الأيام
│   ├── reports/               # التقارير الشهرية، المقارنة، الرسم البياني، وإغلاق الشهر
│   ├── admin/                 # إدارة الشركاء، تعديل الجلسات، وسجل التدقيق (Audit Log)
│   └── settings/              # الإعدادات، المظهر، وتبديل الحسابات السريع
├── firebase_options.dart      # ملف إعدادات Firebase
└── main.dart                  # نقطة الانطلاق مع ProviderScope وتهيئة RTL
```

## 🔐 قواعد أمان Firestore (Security Rules)

تضمن ملفات `firestore.rules` حماية البيانات بحيث:
- لا يمكن للشريك بدء جلسة باسم شخص آخر.
- لا يمكن تعديل جلسة منتهية إلا من قبل المدير مع توثيق السبب.
- سجل التدقيق `auditLogs` للقراءة فقط من قبل المدير وممنوع الحذف أو التعديل نهائياً.

## 🧪 الاختبارات الآلية (Unit Tests)

تم تضمين اختبارات شاملة تغطي:
- حساب النقاط ونسب الإنجاز لمحمد (ساعتان) ومسعود (4 ساعات).
- التحقق من تمايز النقاط بين الشركاء لنفس عدد الساعات المنجزة.
- حساب نسب المجهود الشهرية وسقف النقاط اليومي.
- دمج جلسات متعددة ومعالجة الفوارق الزمنية.

لتشغيل الاختبارات:
```bash
flutter test
```
